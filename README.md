# Python Regression Modeling Projects

This repository showcases two Python projects focused on exploratory data analysis, data visualization, regression modeling, and model evaluation using real-world datasets.

The projects demonstrate practical skills in data preparation, identifying relationships between variables, building predictive models, and interpreting results.

## Projects

### 1. House Price Analysis and Prediction
Explores housing sales in King County, Washington, to identify factors associated with property prices and evaluate regression models for price prediction.

[View House Price Prediction Project](House-Price-Prediction/)

### 2. Medical Insurance Cost Analysis and Prediction
Examines factors associated with medical insurance charges and evaluates regression models for predicting insurance costs.
